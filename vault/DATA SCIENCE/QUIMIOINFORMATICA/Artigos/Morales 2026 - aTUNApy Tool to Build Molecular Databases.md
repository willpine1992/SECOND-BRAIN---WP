## Principais insights (a partir do alerta, sem ler o artigo completo)
- Aponta que construir/manter bancos de dados químicos a partir da literatura é trabalho manual intensivo, porque a informação relevante está espalhada em milhares de publicações.
- Compostos aparecem sob nomenclatura/formatos inconsistentes entre publicações — problema central que a ferramenta ataca.
- Propõe aTUNApy: ferramenta Python de "text-fishing" (garimpo de texto) + unificação + normalização, útil como possível ferramenta de apoio pra organizar a própria base de literatura do usuário.
